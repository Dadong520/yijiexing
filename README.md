# 宜捷行源码备份

此私有仓库保存本地已经打包或冻结的源码，供后续取用。源码备份不等于新版已部署或已完成验收。

## 目录

- `releases/2026-10-24/driver-0.3.5/`：已交付司机端 0.3.5 完整源码包内容。
- `releases/2026-10-24/passenger-native-1.1.5/`：已交付乘客原生端 1.1.5 源码；原生新增开发已暂停，后续乘客入口转微信小程序。
- `releases/2026-10-24/admin-v7/`：已交付后台与共享 v7 后端源码基线；大型截图、运行证据和私人账号数据不在本仓库。
- `candidates/shared-backend-v8/`：本地冻结的待付款规则修复后端候选，不作为云发布或完整联测证明。
- `candidates/driver-0.3.6-r1/`：本地打包司机端 0.3.6 r1 候选，不作为已公开发布证明。
- `SOURCE_BACKUP_MANIFEST.json`：来源压缩包哈希与逐文件 SHA256 校验清单。

## 云服务使用原则

本地完成源码、构建与测试后再上传。Cloud Run 平时暂停，验收由用户通知后才恢复；上传源码、镜像或安装包本身无需开启运行服务。保留的存储及镜像可能仍有少量费用。

本仓库不配置自动部署，不因提交代码而开启谷歌云。

## 凭据与构建

密码、云密钥、私有配置、数据库快照、APK 和构建缓存不上传。换电脑时需要单独配置已授权的云登录、体验凭据及外部服务参数。各组件具体构建方式与已验证/未验证范围以其包内 README 和说明为准。

微信小程序尚在独立开发中，未包含在这次冻结备份内。
