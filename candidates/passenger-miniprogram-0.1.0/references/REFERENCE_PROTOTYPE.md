# 宜捷行乘客原型参考核对

核对日期：2026-10-23（Asia/Singapore）。来源：[宜捷行原型（全）](https://modao.cc/proto/design/pb2mpgpqnskcsp53q)。用户明确说明该原型**不是最新版本**；本次任务、当前后端业务和已确认接口优先。

本次通过 Chrome 独立标签读取可见设计画布、页面目录、设计说明与截图。原型可正常进入，没有密码或权限拦截。未修改原型、未发送评论、未调用隐藏页面状态或内部接口。它是可阅读的设计资料，不等于已找到原乘客小程序源码。

## 实际打开并核对的画布

| 画布 | 可见结构/行为 | 与当前原生体验版关系 |
|---|---|---|
| 乘客小程序 → 首页 | 地图占主要空间；顶部账号与进行中/待支付提醒；底部上下车点卡；用车入口包括一键、预约、代叫、竞价、电话及其他服务 | 当前App以表单卡为主，已有订单入口但不是地图主导布局。青绿色主色一致。未配置地图服务时只能标识为示意，不应画出假导航 |
| 普通叫车 | 起点/终点、最多两途经点、常用地址与历史记录、清空历史、备注；线上计费/司机打表、乘车小费、优惠券预选 | 现有起终点/备注/常用与历史地址基础；UI原仅一个途经点，应补至两个。小费、优惠券、计费模式需要当前业务依据，不能仅凭旧稿套入收费 |
| 司机竞价 | 发布订单、司机列表、确认选择弹窗、待支付、接驾、到达、行程、完成/取消；价格最低/评分最高/距离最近；司机公司、车牌、品牌颜色、评分、完成单量、距起点距离 | 当前已有主流程、价格/最新排序；评分/距离排序及相关司机属性需后端可信字段。建议倒计时和车牌突出；无可信值不能虚构 |
| 一键叫车 | 上车点、备注；无终点、司机打表；预付费抵尾款示意；另有预付页面 | 当前“先叫车稍后补目的地”实现了无终点建单，但要求补目的地后开始行程；属于独立体验简化，不能宣称与旧稿打表计费完全相同 |
| 线下议价 | 微信扫描司机APP二维码进入；等待司机完善订单；核对车牌和起终点/公里/议价金额；价格异议二次确认使司机重报；确认支付；取消/行程/完成/投诉/评价 | 原型与Java `HsOfflineNegotiationController`交叉证实这是乘客适用流程；当前主App最初缺此流程，应按共享订单架构补齐，不能列成纯后台功能 |
| 个人中心 | 头像、昵称、脱敏手机号；乘车记录、代驾记录、优惠券、发票中心、常用地址、出行设置、黑名单、关于我们、问题反馈、分享拉新、积分商城、退出 | 当前已覆盖乘车记录/资料/地址/屏蔽司机/反馈/模拟开票/退出。代驾、优惠券、拉新、商城是旧稿扩展范围，须核对当前业务，不作为已交付能力 |
| 发票中心 | 打车行程开票、代驾服务开票、常用抬头、开票记录、重开记录 | 当前已实现个人/企业抬头与订单模拟回执；正式税务开票、重开链路未配置，不能把模拟回执标成正式发票 |

## 目录可见、未逐页验证的内容

可见目录还包括首页公告/优惠券发放、选择地址、普通/一键/预约/代叫服务订单、电话叫车订单详情、代驾服务订单、车费详情、申请退款、新增常用联系人、用户资料、乘车记录、黑名单、问题反馈、发票重开等。目录存在仅代表设计项目中有该页面名，不能据此断言已实现或已发布。

## 可立即实施的界面差异

1. 首页将“上下车地址 → 订单类型 → 乘车人/备注 → 呼叫”作为一条清晰路径，并将进行中订单提示放在最上方。保留明确的独立体验标识，避免状态提示被长表单淹没。
2. 竞价列表突出价格、车牌和司机身份；选择司机须二次确认。报价截止用服务器 `expiresAt` 显示剩余时间，倒计时结束以服务端状态为准。
3. 起终点编辑支持两个有序途经点；途经点应可移除。与当前后端“最多两个”一致。
4. 无终点订单持续显示“目的地待补充，费用待定”，云端费用详情也不能显示成免费；已退款订单展示模拟退款金额和状态。
5. 个人服务入口分组为出行资料（乘车人/地址）、订单售后（评价投诉/反馈/屏蔽）、费用（抬头/模拟回执）、服务说明；维持青绿主色、白卡片、深色标题，避免将大量技术说明夹在主要操作中。
6. 真实地图/电话/税务平台不可用时展示具体未配置项；仅有示意图或模拟回执时，入口名称与提示应让用户立即理解限制。

这些改动已告知 Android agent。原型为参考材料，未要求照抄旧页面像素或旧费用数字。

后续源码复核：Android 已补首页路线示意卡、上下车地点卡、两个有序途经点、竞价截止倒计时和突出车牌；未填入没有后端依据的评分/距离，也未采用旧稿收费数字。此项为源码已实现的证据，不代替双模拟器和反重力验收。

## 不能机械采用的旧规则

竞价画布可见：示例准入里程10km、报价倒计时2分钟、选司机后支付倒计时5分钟、超时后半小时限下单、部分取消场景2元空车费。普通/一键画布有2元预付、司机打表、小费、优惠券。上述均是旧稿示例或旧业务规则，**没有据此修改当前体验收费策略**；当前报价10分钟到期策略须明确标为独立体验策略，与旧稿存在差异。

原型对竞价排序的文字说明存在“价格最低/评分最高/距离最近”同时又写“倒序排序、可组合”的表述，不能直接作为实现算法。应以价格升序、评分降序、距离升序等明确含义形成当前接口约定，并据可信数据验证。
