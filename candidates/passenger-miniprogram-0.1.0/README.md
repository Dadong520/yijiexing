# 宜捷行乘客微信小程序开发版 0.1.0

这是可导入的开发工程和本地验证资料，不是已发布的微信小程序。当前没有 AppID；微信编译、真机定位及完整云端验收未完成。乘客 Android 新版开发和 1.1.6 候选发布已按要求暂停，旧版交付独立保留。

**两个体验云服务当前均暂停，等用户明确通知验收再开启。** 本包的预览、测试和源码归档均可在云关闭时完成，不要为这些操作启动云服务。数据和镜像保留；暂停计算不代表存储费用归零。

## 先在电脑看界面

Mac 双击 `miniprogram/preview/启动预览.command`，会打开 `http://127.0.0.1:8788/`。电脑需有 Python 3。预览使用实际页面源码，显示只读示例数据，顶部标有“非微信运行”；不能下单、支付或定位。只监听本机，没有开机自启。

如提示端口被其他目录占用，可使用已经运行的本地预览，或由维护者确认后关闭旧预览；启动器不会擅自替换其他程序。

## 导入与复跑

微信开发者工具导入 `miniprogram/`，详细步骤、地图接入和外部服务限制见 `miniprogram/README.md`。当前 `touristappid` 只是占位，不具有发布资格。

本地验证需要 Node.js 和 Python 3。在 `miniprogram/` 执行 `npm test` 与 `npm run check`；无外部 npm 依赖，无需 `npm install`。真实后端契约测试使用本包 `backend-frozen-v8/` 和临时数据库，不连接原环境或云环境。

## 包含内容

- `miniprogram/`：8 个原生微信页面、接口和状态管理、地图适配、测试、只读预览。
- `backend-frozen-v8/`：配套共享后端冻结源码，用于复跑本地契约测试；不是独立批准的再次部署指令。
- `references/`：旧原型、原源码搜索与接口核对资料。这些是历史依据，不能替代当前版本验证结论。
- `evidence/`：测试输出、独立复核、截图和停服记录。
- `VALIDATION.md`：本版实际验证清单与待验收项。
- `SOURCE_MANIFEST.json`：逐文件 SHA-256；ZIP 的外部校验值在同级 `SHA256SUMS.txt`。

没有打包实际访问码、管理令牌、AppSecret、云密钥、数据库、APK 或构建缓存。原独立乘客小程序源码仍未找到，本工程不能声称完整还原历史产品。
