# 宜捷行乘客微信小程序开发版

2026-10-24。根据用户最新决定，乘客 Android 后续开发和 1.1.6 候选公开发布已暂停，保留旧版与验收记录。本目录是新的原生微信小程序工程，沿用独立体验云和司机端共用订单。未连接原测试或生产环境。

**当前云端按用户要求保持暂停。** 登录、刷新和写入云订单暂时不可用；不要为查看源码或本地测试启动云服务。开发、测试与打包在本地完成，实际云端验收等待用户明确通知开启。源码上传和归档无需启动 Cloud Run。本开发版尚未上传微信平台或取得真机体验二维码。

## 无账号时先看界面

在 Mac 双击 `preview/启动预览.command`，浏览器打开本机 `http://127.0.0.1:8788/`。也可用 Python 3 执行 `python3 preview/start_preview.py --open`。这会展示实际页面源码生成的只读界面和明确标记的示例数据，不连接云、不下单、不定位。它不是微信运行环境。若端口已被其他目录的预览占用，启动器会提示并退出，不会关闭其他程序。

## 打开开发版

1. 安装官方[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。选择导入项目，目录选本文件所在的 `miniprogram`。
2. 当前没有小程序账号和 AppID，工程使用 `touristappid` 占位。可按开发工具提供的游客/测试项目入口查看；这不是可发布的 AppID，工具当前版本若不支持游客导入，需要注册账号后替换 AppID。
3. 等用户明确开启云端验收后，界面从“我的 → 登录体验账户”进入，输入独立体验访问码和白名单手机号，例如 `13800000102` 或 `13800000103`。访问码保存在项目外 `yijiexing-cloud-20261023/.private/driver-access-code.txt`，没有打包在本源码中。验证码在界面显示，**未发送短信**。
4. 体验服务固定为 `https://driver-demo-491829048305.us-west1.run.app`。开发工具如因合法域名未配置阻止请求，只在本机开发调试中按工具提示使用“不校验合法域名”选项；正式配置必须通过小程序后台的合法域名校验，不能把开发选项当成真机发布方案。
5. 暂无账号时，选择“已有 / 体验地点”可准备合成订单。所有体验地点均为明确标记的测试地点，并非设备定位结果。费用是体验估算，禁止用本环境安排真实出行。

登录凭据和原请求重试记录使用微信本地 storage 保存，不是硬件加密保险库。退出会撤销当前服务端会话并移除本地凭据；原请求记录按乘客身份隔离。结果未确认的操作需点“原请求重试”，不能另造订单或重复支付。

## 地图选点

默认采用 `wx.chooseLocation`，地图组件使用 GCJ‑02 坐标。请求上下车点由用户主动点击触发，不自动或持续采集位置。服务端与司机现有订单使用 WGS84；提交前转换为 WGS84，展示时再转换为 GCJ‑02。地图仅显示地点和司机上报位置，不提供道路导航或真实路径计费。

腾讯位置服务地图选点插件也已留接入方式。根据[官方插件指南](https://lbs.qq.com/miniProgram/plugin/pluginGuide/locationPicker)，需要在小程序后台添加插件、申请腾讯位置服务 Key、设置应用名称和定位授权。当前指南示例版本为 1.2.1，provider 为 `wx76a9a06e5b4e693e`。

有 AppID、插件使用批准和对应公开地图 Key 后，可在项目目录执行 `node scripts/configure-map.js plugin`，通过环境变量 `YIJIE_MAP_KEY` 和可选 `YIJIE_MAP_REFERER` 传入。该命令只生成本工程的 `app.json` 与 `config/location.js`，**不能输入 AppSecret**。恢复默认接口执行 `node scripts/configure-map.js native`。默认不声明未获批准的第三方插件，以免游客工程因插件身份校验直接失败。

官方接入页没有承诺所有调用无限免费。本开发版不创建付费服务；额度、计费、应用资质及地图接口权限以正式账号控制台为准。真实选点、权限拒绝后的恢复、插件真机返回、正式域名可达性均需账号配置后实际验证。

## 已实现页面和业务

- 打车：即时、预约、司机竞价、暂不填目的地、最多两个途经点、代叫乘车人、备注及已有地址。
- 行程：订单列表、司机报价选择、各阶段同步、取消、司机取消后继续呼叫、补充目的地、费用调整详情与模拟付款。
- 行程售后：评价、投诉、图片附件提交、后台处理记录、屏蔽司机。
- 线下议价：扫码或手动填写体验码、认领、价格异议、重新报价后的版本确认与模拟付款。
- 我的：资料与城市、常用地址、乘车人、发票抬头、模拟开票回执、反馈、屏蔽司机、公告与服务说明。

页面接入现有服务端持久化动作；上述“已实现”不代表已在微信真机逐项验证。支付、退款、开票回执仍为模拟。没有接入微信 openid 登录、真实手机号授权、真实短信、正式发票、推送、电话中继和人工客服。原乘客小程序源码仍未找到，本工程依据旧原型、原 Java 功能核对和当前共享接口重新实现，不能声称逐页还原全部历史功能。

## 验证与交付范围

`npm test` 运行本地数据层、页面行为与真实隔离后端契约测试；`npm run check` 检查项目路径、页面注册、配置、JS 语法和条件绑定。测试不会联系原环境。真实后端契约测试使用临时 SQLite 和本机 HTTP 服务。

交付包自带同级 `backend-frozen-v8/`，所以解压后进入 `miniprogram/` 即可复跑；需要 Node.js（支持 `node:test` 和内置 `fetch`）与 Python 3，无需先运行 `npm install`。自行拆分目录时，用 `YIJIE_BACKEND_SOURCE` 指向配套后端源码。本地测试不需要云端访问码或小程序 AppID。

`preview/` 提供复用实际页面源码的浏览器视觉预览，仅用于页面与交互入口检查。它明确显示“非微信运行”，地图为占位，业务写操作不会发送到云端，也不会伪造成功。不能将该预览视为微信编译、微信插件或真机定位测试。

当前没有正式小程序二维码和上传发布版本。微信开发工具编译、真机位置权限、域名备案/白名单配置及插件真实运行尚未验证。实际测试数量与证据见交付目录报告，不把源码可解析等同于全部验收通过。
