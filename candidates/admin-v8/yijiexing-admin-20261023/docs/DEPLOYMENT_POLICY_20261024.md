# 当前体验环境发布规则（2026-10-24 用户授权）

本规则取代此前“等用户通知验收才恢复云服务”“测试后不得直接部署”“部署完成自动暂停”的约束。

- 当前项目范围内的修改，通过适用测试后，可以直接发布到独立 Google Cloud 体验环境，不必逐次申请部署许可。部署后进行健康、权限及相关业务回归，记录版本和结果；失败时回滚，不把未验证项目写成通过。
- driver-demo 与 driver-admin 已恢复 automatic / min 0 / max 1。空闲自动缩容；不设置保活，不在工作结束时自动手动暂停。暂停仅在用户要求或明确故障处置需要时进行并说明。
- 保留请求计费、IAM、账户权限、持久化数据和接口兼容；不连接原测试或生产环境。保留可回滚版本，禁止重置账户或订单数据。
- 共享后端必须指定一个发布负责人；Codex 和反重力使用独立目录与分支，避免同时发布、覆盖或修改重复快照。
- 后台应支持其他设备浏览器访问，保留身份验证；不得将管理员凭据、云密钥或管理令牌放入前端。跨设备 HTTPS 入口已部署，并在 Chrome 完成 Google 登录与管理账号登录验证；其他实体设备尚未实测。
- 大文件传输优先直连，直连失败后才使用现有代理。乘客端继续微信小程序方向。

本规则允许测试后部署，不代表已安装 GitHub 自动部署流水线，也不代表历史候选版本已通过新一轮验收。
