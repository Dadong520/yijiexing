## 后台访问与测试身份

后台界面本轮不改。当前电脑双击工程根目录的 [启动后台.command](../启动后台.command)，或在后台工程目录执行 `python3 ops/serve.py`，启动后访问 [后台本机入口](http://127.0.0.1:8790)。双击启动后关闭窗口不会停服务；直接执行 ops/serve.py 的前台模式可按 Ctrl+C 停入口。两者均不暂停手机云服务。

本机需要 Python 3、Google Cloud CLI，以及已获管理服务调用权限的云账号。管理服务保持 IAM 私有；不要将云管理地址改为公开访问。账号与凭据位置如下，只说明本机存放位置，不在本文披露内容：

| --- | --- |
| 后台管理员 | 用户名 `admin`；初始随机密码位于后台 `.private/admin-bootstrap-password.txt` |
| 运营和只读验证 | `qa_operator` / `qa_viewer`；私密账号记录位于后台 `.private/qa-accounts.json` |
| 本机外层管理令牌 | 同级 `yijiexing-cloud-20261023/.private/admin-token.txt`，由本机入口读取，不进入网页代码 |
| 手机体验访问码 | 同级 `yijiexing-cloud-20261023/.private/driver-access-code.txt`；与管理员密码分离 |

手机采用体验验证码，不发送真实短信。换电脑需要另行配置已授权的云登录及私下提供的体验凭据；解压源码不会自动获得访问权限。凭据、会话及 `.private/` 不进入公开源码包。

所有支付、退款和提现为模拟。真实短信、支付渠道、推送、实名认证、电子发票等外部配置边界不因界面优化改变；地图示意、体验估价不等于真实道路计费。详细范围见 [功能状态](FEATURE_STATUS.md) 和 [问题记录](ISSUES.md)。

暂停/恢复整个体验环境仍使用既有 `yijiexing-cloud-20261023/ops/cloud-control.sh pause`、`resume`、`status`。本轮文档工作未实际执行启停。保留按需运行、最小实例 0、服务级最大实例 1；revision 级上限 3 和 CPU throttling 保持原配置，不能混称所有层级上限 1。暂停不删除持久化数据，保留存储仍可能产生少量费用。
