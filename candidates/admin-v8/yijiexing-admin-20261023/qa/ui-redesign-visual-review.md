乘客最终 115 的系统 1.5 倍地址键盘弹窗，取消和使用此地点均完整位于键盘上方；大字投诉键盘弹窗中返回和确认提交按钮也完整。投诉描述为空且字段标明至少 5 字，确认提交禁用与当前空表状态一致，不判为 UI 故障。司机 r2 的大字投诉键盘/确认、订单详情及会员结算画面中关键按钮完整可见。已看证据范围内未发现新的已确认视觉发布阻断；这不是全部页面或业务操作均通过的结论。
