## 范围与结果

实际导航打车、行程、我的、订单详情、登录、地点选择、设置和线下议价八页，检查返回、底部导航、可滚动表单及中文提示。七类页面有本报告目录中的PNG，行程列表本轮只保留导航观察，不能声称全部八页均已逐像素验收。最终首页、我的、发票设置、订单详情、登录、地点选择和议价截图已读取像素。页面采用统一卡片、绿色主操作、浅色背景；当前浏览器检查未发现遮住关键操作的剩余阻断。

本轮发现并由小程序负责人修复、根会话刷新复查的问题：

1. 浏览器将自闭合 textarea 当作未结束元素，后续按钮被吞入；预览适配器改为成对非空标签，重新显示备注后的主按钮。
2. 样式转译错误匹配 .page，影响输入/按钮布局；修复作用域与默认按钮样式，重新检查首页及表单。
3. 地图占位文字断行、无上下车点时的空值展示；安全回退后重新查看首页。
4. 原始枚举、ISO时间及技术版本文字暴露给乘客；改为中文及本地时间，隐藏费用版本和技术订单编号字样，订单编号查看功能保留。付款金额/版本冻结仍由独立代码测试验证。

只读预览明确显示“浏览器视觉预览 · 只读示例数据 · 非微信运行 · 地图权限待配置”。点击评价提交、模拟验证码等写动作显示只读提示，没有发送云请求或伪造业务成功。地图选点显示尚需微信环境和权限；体验地点标明不是当前位置。截图 mini-11-login-validation.png 记录的是只读阻止，不是实际登录表单校验通过。
