# 权限、新单提醒与接送距离确认验收

本轮仅在独立体验项目 yijiexing-driver-demo-1023 / us-west1 执行。未接原生产/测试环境，支付为模拟。根协调者统一发布。

## 实际实现
- 两Android首开用途说明、可稍后授权、系统授权/设置引导、后续权限检查入口。司机检查精确定位、Android通知渠道、悬浮窗和后台电池设置；乘客只申请必要前台定位。
- 听单期间司机前台明显新单卡、通知/声音；后台前台服务轮询新单，有系统授权及权益时显示约20秒新单卡，点击只看详情。队列按新单优先，同一提示退休后不每15秒重复弹。
- 接客和送达服务端检查实际WGS84位置。默认300米，位置缺失、过旧、精度差都需乘客明确同意，不把未知距离当0。本人拒绝不推进；确认180秒过期，状态变化后失效，重复请求不重复推进或入账。
- 后台城市与会员→接送距离规则：接客/送达分别50–5000整数米，全国→大区→城市继承，草稿与发布分开，保留理由和操作审计。详情展示规则快照、未知距离及乘客确认历史。
- 修复免访问码后的旧服务启动保护；修复定位关闭时启动服务再打开定位无法恢复采样。未申请绕过系统强杀的能力。
