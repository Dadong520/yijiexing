**目前仍未找到独立乘客小程序源码。** 已在本机 Documents、Downloads 及企业微信下载缓存中搜索小程序/uni-app 入口和乘客相关工程，成功检查 80 个 ZIP 的目录。

- 本次没有递归检查每个压缩包中的二次压缩包；RAR/7z 只检查了名称。结论是“在已查范围内未找到”，不是断言其他磁盘或远程仓库不存在。

本次使用独立环境，未连接或修改原来的测试环境，也没有把原环境密钥写入交付包。访问码、登录令牌和一次配对码不应放进公开截图或文档。

## 旧原型的使用方式与差异

用户提供的 [宜捷行原型（全）](https://modao.cc/proto/design/pb2mpgpqnskcsp53q) **不是最新版本**。本次已读取首页、普通叫车、司机竞价、一键叫车、线下议价、个人中心和发票中心；其他只见目录的页面没有当作已实现功能。核对详情见 [原型参考报告](../REFERENCE_PROTOTYPE.md)。

| 原型内容 | 当前体验版 | 需要明确的差异 |
|---|---|---|
| 地图作为首页主体 | 1.1.5以起终点卡为首页主体，订单路线示意可展开；支持体验地标及手工坐标 | 不是正式地图搜索、道路路线或导航 |
| 最多两个途经点 | 已支持两个有序途经点 | 全部设备交互需按实际验收记录判断 |
| 一键无终点、司机打表 | 可先叫车，目的地和费用待定；补目的地后才能开始行程 | 1.1.2已实测无终点创建、费用待定和取消；补目的地开行程未做完整设备验收，不等同于原稿无终点打表及其预付规则 |
| 竞价价格/评分/距离排序 | 当前价格和最新报价排序，报价倒计时、车牌显示 | 缺可信评分/距离数据时不编造；不能称完整还原原稿排序 |
| 旧稿 2 元预付、2 分钟报价、5 分钟支付、取消费用等 | 使用独立体验计价与 10 分钟报价有效期 | 没有机械套用旧收费数字；不作为正式营运规则 |
| 扫司机码后等待司机补单 | 当前司机先完善议价单，生成 5 分钟一次码，乘客认领并确认/提出异议 | 支持粘贴码及外部扫码工具打开深链接，App 无内置相机扫码器；1.1.2/0.3.3双端粘贴码认领、异议重报和模拟支付完单已由Codex实测，详见验证清单 |
| 开票与重开记录 | 抬头管理及明确模拟回执 | 不等同于真实税务开票与重开 |
| 优惠券、积分商城、分享拉新、代驾等菜单 | 旧稿存在对应目录 | 还未证实本次当前业务范围与完整实现，不能列为已交付通过 |

## 模拟能力与缺配置项

| 能力 | 当前状态 | 用户体验中的真实含义 |
|---|---|---|
| 支付 | **模拟** | 可选择成功、失败、处理中或取消，不连接支付网关、不扣真实资金 |
| 退款 | **模拟** | 按体验订单状态记录退款金额与结果，不产生真实资金退回 |
| 发票 | **模拟回执** | 可保存抬头、申请并查看记录；不能报销，不是正式税务发票，无正式开票/重开渠道 |
| 短信验证码 | **未接真实短信服务** | 体验验证码由云端返回，没有向手机号发送短信 |
| 乘客地图搜索、地址解析、地图底图 | **未配置正式地图服务** | 提供体验地点、常用/历史地址及手工坐标；地址文字不会自动变成准确坐标 |
| GPS 自动定位 | **乘客端未接入** | 不会自动获取乘客当前位置；模拟器宜昌坐标是验收设置，不是真实定位证据 |
| 司机位置 | **只展示司机上报数据及时间** | 有上报时可展示；不保证连续实时定位，也不代表已验证真车移动轨迹 |
| 乘客路线、道路导航、实时路况与 ETA | **未接正式服务** | 坐标连线为示意，体验估价使用粗略距离；不能作为道路导航、准确到达时间或营运计价 |
| 联系司机、电话中继、电话叫车坐席 | **未配置** | 不提供实际电话中继；原电话叫车后端入口不能直接当作已完成的乘客电话渠道 |
| 厂商推送 | **未配置** | App 前台周期同步，不能保证后台、锁屏或进程结束后实时提醒 |
| 投诉与反馈后台处理 | **可保存、查看和回复** | 已有后台回复回读及乘客界面证据；状态由实际后台操作改变，不自动生成处理结论 |
| 实时人工客服 | **未接入** | 后台留言回复能力不等同于实时客服、电话服务或全天候人工处理 |
| 发票邮件等外发渠道 | **未配置** | 模拟回执不会发送正式发票邮件 |

司机端与乘客端能力分别说明：司机已有GPS上报、MapLibre底图与公共OSRM路线，不能等同于正式商用导航、真车道路准确性或连续定位验收；乘客端仍未接正式地图搜索和自动GPS。截图中的Wujiagang为伍家岗英文标注，不能据此判位置错误。司机首页“今日”收入/单量当前使用v7演示累计值，未实现跨日清零，这是已保留的已知限制。

真实支付渠道按本次要求排除；其他外部服务缺配置和上述业务差异并没有被默认为“全部完成”。本次可体验的范围与仍待验收项均应按验证清单逐项查看。
