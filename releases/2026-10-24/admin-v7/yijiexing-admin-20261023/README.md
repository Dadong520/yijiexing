## 启动访问

前提：本机已安装 Python 3 和 Google Cloud CLI，并登录已获 `driver-admin` 调用权限的云账号；既有 `yijiexing-cloud-20261023/.private/admin-token.txt` 保留在本机。

双击 `启动后台.command`，或者在此目录执行 `python3 ops/serve.py`。浏览器打开 <http://127.0.0.1:8790>。窗口必须保持运行；按 Ctrl+C 关闭本机访问入口。

入口只监听本机，校验 Host 和跨站来源。云 IAM 身份与外层管理令牌仅由本机进程读取并转发，不进入网页代码。管理账号登录使用独立会话；刷新页面后重新登录。不要将 `.private/`、密码或会话放入公开交付包。

初始管理员用户名为 `admin`，独立随机密码保存在本目录 `.private/admin-bootstrap-password.txt`（仅本机所有者可读）。该密码通过独立 Secret Manager secret 仅提供给管理服务，不与手机访问码或外层管理令牌混用。

## 暂停和恢复

关闭本机入口仅关闭浏览器访问通道，不暂停手机服务。暂停整个体验环境使用既有脚本：

```sh
bash ../yijiexing-cloud-20261023/ops/cloud-control.sh pause
bash ../yijiexing-cloud-20261023/ops/cloud-control.sh resume
bash ../yijiexing-cloud-20261023/ops/cloud-control.sh status
```

暂停脚本保留云端数据；恢复脚本目标为按需运行，最小实例0、最大实例1。最终v7读回为服务级automatic/maxScale=1，revision级maxScale=3仍保留且CPU throttling=true；不能把服务级与revision级混称每一级max1。本轮为避免打断三端联调未在此文档更新中实际执行启停；执行后应使用status核对结果。暂停计算后，保留的数据与镜像仍可能产生少量存储费用。管理服务保持 IAM 私有，不能以直接公开管理地址代替本机入口。真实短信、支付渠道、地图路线、厂商推送、实名认证与电子发票是否接通见功能矩阵；模拟支付、退款、提现不产生真实资金交易。

## 三端状态及外部服务说明

司机取消标准/预约/竞价订单后，订单权威状态为`WAIT_CONTINUE`，乘客可继续叫车或结束订单。旧司机App暂显示该司机参与“已取消”（`CANCELLED`），后台明确说明两者含义；这项兼容期并非三端阶段字段字面一致。继续后使用同一订单编号重新等待司机，正式结束才是订单CANCELLED。详细验收要求见[验收记录](docs/ACCEPTANCE.md)。

支付、退款、提现全部为模拟，不发生真实资金流。短信采用体验验证码；地图估价仍属体验口径；司机0.3.2已验证唤起高德并显示中文接驾点/终点，真实路线计价未接入；推送、电话中继、实时人工客服、实名认证及真实电子发票尚缺相应外部配置。后台能够查看和回复已保存反馈投诉。各服务已实现部分、尚未接通部分和条件见[外部依赖及缺陷说明](docs/ISSUES.md)。
