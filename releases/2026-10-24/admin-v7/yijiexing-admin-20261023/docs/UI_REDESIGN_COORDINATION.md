## 范围与交付边界

本轮按用户新要求优化司机 App 和乘客 App 的全部适用页面，再统一回归、协调发布。乘客端借鉴滴滴、Uber 成熟产品的简洁信息组织与清楚的操作顺序，保留宜捷行品牌及既有业务；司机端面向年长出租车司机，采用大字、大按钮、清楚的状态与主操作，减少阅读和寻找按钮的负担。这里记录的是设计方向；已有官方 Uber 叫车页参考，未宣称审查了滴滴或 Uber 手机端完整内部流程。

后台界面保持现状，只作为三端业务核对入口。共享后端冻结在 v7，不因视觉调整改变订单编号、业务状态、金额、权限、持久化数据或接口契约。发现确需后端变更的阻塞问题时，先由共享后端负责人记录兼容方案并协调，不并行发布临时修改。

此前公开 APK 是已经验证部分业务流程的**功能基线，不是本轮最终 UI 交付**。既有功能证据、测试报告和历史版本记录保留原文。本轮建立新证据目录，以实际安装版本与截图重新验收，不能沿用旧版本通过结论替代新界面验证。
