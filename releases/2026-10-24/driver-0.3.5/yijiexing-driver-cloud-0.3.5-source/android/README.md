## 首次使用

1. 安装生成的云端体验 APK。
2. 点“设置演示访问码”，输入单独提供的访问码，只需保存一次。
3. 使用 13800000001 获取演示验证码，勾选体验说明后登录。
4. 如果云端已暂停，在电脑恢复服务后，点“重试连接”。已有登录状态会加密保留；冷启动失败时可点“重试连接，继续原账号”，无需重新获取验证码。首次恢复可能需要等待冷启动。

访问码和登录会话分别用 AndroidKeyStore AES-GCM 加密保存于应用私有目录；不会存入 APK、构建参数或项目资源。清除应用数据或在连接设置中清除访问码后需重新输入。地址仅公开服务域名，域名不包含访问凭证。

## 构建

使用 Java 17、Gradle 8.7、Android SDK 34。自行设置 `local.properties` 的 `sdk.dir`。

```sh
./gradlew -PYIJ_CLOUD_ORIGIN=https://driver-demo-491829048305.us-west1.run.app testDebugUnitTest assembleDebug
```

`YIJ_CLOUD_ORIGIN` 只接受不含路径、端口、查询参数的 HTTPS origin，写入 BuildConfig。未提供时值为空，App 会禁用登录及网络业务请求，并提示安装已配置的体验包。运行时无法把访问码发到任意第三方地址，HTTP 重定向也不会跟随。

不要把演示访问码、管理员令牌或 Google Cloud 凭证写入 Gradle 参数、源码或资源。

## 请求与费用控制

- 前台状态刷新 10 秒一次，仅界面可见时刷新。
- 正在听单或行程时保留原生前台位置服务，后台状态同步约 15 秒一次；位置至多约 15 秒上报一次。
- 停止听单且没有进行中的行程后停止位置服务，App 进入后台后也不再前台轮询。
- 访问码被拒绝或收到停用状态时停止自动刷新；暂停后的恢复需要手动重试。
- 暂时断网时逐步延后刷新，不自动重发支付、提现等业务操作。
- 云端连接超时 20 秒，读取超时 75 秒；前台等待超过 8 秒会显示冷启动说明。

地图瓦片与示例道路服务仍通过公开地图服务取得，未将其当作正式营运导航。公共服务的许可、流量、SLA、隐私处理需在生产上线前确认。

测试、构建及模拟器/设备验证范围以顶层候选说明与后续验收记录为准；本说明不表示正式第三方支付或原Java微服务已接入。
